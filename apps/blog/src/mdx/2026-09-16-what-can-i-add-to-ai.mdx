Astra가 작성한 코드를 보고 한동안 읽을 엄두가 나지 않았습니다.

아래는 당시 Astra가 작성한 코드의 일부입니다.

{/* prettier-ignore */}
```tsx
function Content({ content, evidence }: { content: TestContent; evidence?: (id: string) => void }) {
  return <div className="test-content"><h4>사전 조건</h4><ul>{content.preconditions.map((p,i) => <li key={i}>{p}</li>)}</ul><h4>실행 절차</h4><ol>{content.steps.map((s,i) => <li key={i}>{s}</li>)}</ol><h4>기대 결과</h4><p className="expected">{content.expected}</p><h4>근거 구절</h4><div className="evidence-links">{content.evidenceIds.length ? content.evidenceIds.map(id => <button type="button" className="evidence" key={id} onClick={() => evidence?.(id)}>{id}</button>) : <span className="muted">근거 없음, 확인 필요</span>}</div></div>
}
```

코드의 양도 많았고 어디서부터 읽어야 할지도 막막했습니다.

처음에는 “이런 걸 내가 이해할 수 있을까?”라는 생각이 들었습니다. 곧 “이해를 꼭 해야 할까?”라는 질문으로 이어졌습니다. 이해할 필요가 없다면 사람은 무엇을 해야 할까요? 이해해야 한다면 어디부터 어디까지 알아야 할까요?

AI에게 처음 던진 질문은 좋은 코드에 관한 것이었습니다. AI가 코드를 작성해도 좋은 코드의 기준은 같은지 물었습니다. 사람이 직접 좋은 코드를 쓰는 능력도 여전히 필요한지 물었습니다. 그런데 왜 이런 질문을 했는지 돌아보니, 더 개인적인 고민이 있었습니다.

> 내가 코드를 작성하지도 않고, 작성된 코드를 이해도 못하면 나의 존재의의는 뭐지? 나의 포지션은 뭐지?

이 질문을 두고 AI와 대화했습니다. 아래에는 실제 대화를 읽기 좋게 줄이고 다듬어 담았습니다. 대화 사이에는 제가 왜 다음 질문을 했고, 무엇을 이해했는지 덧붙였습니다.
