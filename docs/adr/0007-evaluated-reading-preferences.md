# 시편에서 고른 읽기 방식을 블로그에 적용한다

2026-11-09에 확정한 블로그 시편 선택을 적용한다. [ADR 0006](0006-question-dial.md)의 질문 다이얼 방향과 서체, 색상, 교육 데모 보호는 유지하고 아래 읽기 방식만 대체한다.

- 홈 질문 다이얼은 무대 절반마다 한 칸 넘어간다. 한 칸 멀어질 때 배율은 0.22씩 줄여 최소 0.5, 불투명도는 0.34씩 줄여 최소 0.18로 둔다. 항목의 원래 높이를 확보한다. 소개 페이지의 릴 설정은 바꾸지 않는다.
- 글의 절 안내는 제목이 화면 위에서 96px인 읽는 선을 지날 때 바뀐다. 데스크톱에서는 모든 절을 스크롤 가능한 목록으로 보여 준다. 휴대폰 보조 띠에는 현재 절 이름만 둔다.
- 긴 코드는 줄바꿈하고, 실제 높이가 240px를 넘을 때만 펼치기 버튼을 둔다. 복사는 접힘 여부와 관계없이 코드 전체를 대상으로 하고 완료 문구는 1200ms 동안 보인다. JavaScript 실행 전에는 전체 코드를 읽을 수 있다.
- 본문은 17px와 줄 간격 1.75를 유지하고 직접 이어지는 단락 사이를 24px로 둔다. 640px 이상 화면에서 글의 본문은 기존 읽기 열 안쪽 폭의 85%를 쓴다. 시편은 상대 폭을 비교했으므로 전체 사이트를 85vw로 정하거나 제목의 폭을 줄이지 않는다. 휴대폰은 기존 가용 폭을 쓴다.
- 목록의 제목과 설명은 각각 두 줄까지 보이고 날짜, 읽기 시간과 주제는 설명 아래에 둔다. 검색과 필터로 결과가 바뀔 때 행을 움직이거나 흐리지 않는다.
- 글을 연 출발 화면이 있으면 복귀 링크는 돌아가기로 표시하고 그 방문 기록으로 돌아간다. 목차의 해시 이동은 출발 화면을 대체하지 않는다. 방문 기록 API를 쓸 수 없으면 기록한 출발 주소로 이동하고, 새 탭과 직접 방문은 모든 글로 안내한다.
- 대화 인용은 좌우 교대와 말풍선을 유지하고 발화 최대 폭을 80%, 말풍선 모서리를 4px와 16px로 둔다. 이 변경은 인용의 외형만 다루며 교육 데모의 동작과 게시글 문구는 바꾸지 않는다.
- 인용문은 양옆 20px 들여쓰기로 구분한다. 보충 설명으로 작성한 MDX `aside`와 `details`는 접힌 상태에서 시작하고 14px, 줄 간격 1.75와 보조색으로 표시한다. 기존 문단을 임의로 보충 설명으로 분류하지 않는다.
- 홈에서 글을 열 때 같은 비율의 제목은 300ms의 ease-out-cubic으로 이동하고, 본문은 제목이 도착한 뒤 180ms 동안 나타난다. 본문 자체를 숨기지 않고 View Transition의 스냅숏에만 표시 지연을 적용한다. 미지원, 저감 모드와 중단 경로에서는 일반 탐색과 본문의 가독성을 보장한다.

코드와 정적 검사로 선택값, 의미 보존과 저감 모드 분기를 확인한다. 실제 넘침, 서체 로딩, 화면 전환의 깜빡임과 감촉은 별도 화면 검사 없이는 검증 완료로 보지 않는다.
