# 시각 방향은 "연구 노트, 여백 색인"으로 고정한다

모든 글은 번호가 붙은 실험 항목으로 원장(ledger)에 기록되고, 왼쪽 여백의 색인이 스크롤을 따라 지금 읽는 항목을 가리킨다. 항목 번호는 전체 글 수에서 계산한 실제 순번이고, 근거 줄(읽기 시간, 주제)은 글 데이터에서만 나온다. 여백 색인은 home의 연도, blog의 경로, post의 섹션과 읽기 진행선을 소유하며 스크롤에 반응하므로 문서나 슬라이드로는 성립하지 않는다.

토큰은 `packages/ui/styles/globals.css`가 전역으로 소유한다. 종이와 잉크 두 톤에 accent 하나(`--accent-ink`)만 두고, accent의 의미는 "지금 위치와 행동"으로 제한한다. 구획은 괘선(`--rule`)으로만 하며 카드, 그림자, 반투명 blur를 쓰지 않는다. 서체는 한글 글리프를 가진 IBM Plex Sans KR과 데이터 전용 IBM Plex Mono이며, mono는 숫자, 날짜, 항목 번호, 코드처럼 값이 데이터일 때만 쓴다. 한글 라벨에 uppercase와 넓은 자간을 적용하지 않는다.

모션은 목적 기준 family로 예산을 센다. shell은 nav 활성 밑줄, home과 blog는 색인 marker 이동과 hover 색 전환, 무한 스크롤 skeleton, post는 색인 marker와 읽기 진행선, 코드 복사 피드백까지다. 진입 fade-up, stagger, 컨테이너의 opacity 0 시작, 필터 변경과 키보드 트리거 애니메이션은 넣지 않는다. 본문은 애니메이션이 실행되지 않는 실행면에서도 읽혀야 하므로 장식 요소만 움직인다. `prefers-reduced-motion`은 전역 일괄 정지 대신 family별로 이동만 제거하고 위치, 상태, 색 정보는 남긴다.

`apps/blog/src/mdx/components/**`는 이 결정의 범위 밖이며 ADR 0002에 따라 손대지 않는다. about 페이지는 2026-09-04에 같은 체계로 편입했다. about은 노트의 표지로서 이름과 역할이 괘선 양 끝에 놓이고, 고정된 괘선 무대가 첫 화면을 지나면 물러나며, 측정 기록이 스크롤에 따라 한 건씩 드러난 뒤 경력, 오픈소스 PR, 도구, 연락으로 이어진다. 외부 reference(OpenAI 제품 소개 페이지)에서 빌린 것은 고정 무대, 양 끝 제목, 순차 문장 드러남, 탭형 증거 패널이라는 관계뿐이고 검은 배경과 WebGL 글로우 같은 브랜드 표현은 빌리지 않았다. 스크롤 연동은 Motion의 useScroll로 구현한다. 표지 제목은 스크롤에 따라 양 끝으로 벌어지고, 측정 4건은 한 화면에 고정된 채 스크롤로 교체되며 숫자가 from에서 to로 세어진다. JS가 실행되기 전과 저감 모드에서는 측정이 정적 목록으로 렌더되어 모든 내용이 읽힌다. three.js 기반 3D 무대(와이어프레임 지형, 입자 은하)는 2026-09-04에 시도했다가 사용자 판정으로 제거했고 의존성도 되돌렸다. 표지 배경은 CSS 괘선 무대 하나로 유지한다.

자동 검사가 닫는 것은 금지 패턴 grep, 정적 검사, E2E의 시맨틱 selector까지다. 미감, pacing, 좁은 화면의 시각 붕괴는 사람이 실제 화면에서 판정한다. 방향을 바꾸는 결정은 이 ADR을 갱신하고 새 ADR로 대체한다.
